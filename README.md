# 🍺 Análisis de Mercado Cervecero — SQL + R

## Descripción
Análisis completo del rendimiento productivo y comercial 
de una cervecería usando SQL para extracción y agregación 
de datos y R para visualización estadística. Desarrollado 
como parte de mi portafolio orientado al sector bebidas 
y gran consumo.

## Objetivo
Identificar patrones de producción, calidad, eficiencia 
y rentabilidad por estilo de cerveza y localización, 
extrayendo insights accionables para la toma de 
decisiones comerciales.

## Dataset
- **Fuente:** Kaggle — Brewery Operations and Market 
  Analysis Dataset
- **Tamaño:** 583 registros × 20 columnas
- **Periodo:** Enero — Diciembre 2020
- **Motor SQL:** SQLite (DBeaver)

## Herramientas y Tecnologías
- **SQL / SQLite** — extracción y agregación de datos
- **DBeaver** — gestor de base de datos
- **R / RStudio** — análisis estadístico y visualización
- **ggplot2** — gráficos de alta calidad
- **tidyverse** — manipulación de datos

## Consultas SQL Realizadas
- Ventas totales por estilo de cerveza
- Eficiencia de producción por localización
- Calidad media por estilo (pH, alcohol, amargor)
- Análisis de pérdidas por fase de producción
- Evolución mensual de ventas
- Top 10 lotes más rentables por litro

## Insights Clave
- 🍺 Pilsner lidera en ventas totales
- ⭐ Pilsner y Lager empatan en calidad (9,57/10)
- ⚠️ Lager presenta las mayores pérdidas de producción
- 📈 Mayo es el mes de mayor facturación
- 💰 Sour domina el Top 10 de rentabilidad por litro
- 🏭 Marathahalli es la localización más eficiente
